# GitHub repository

Project URL: https://github.com/vchen82/nyc-open-data-portfolio

The public repository includes the complete warehouse project, documentation, and independent local demo. Preserve the top-level `README.md`, `warehouse/`, and `examples/` structure when updating it.

Clone the published repository before making future changes:

```bash
git clone https://github.com/vchen82/nyc-open-data-portfolio.git
cd nyc-open-data-portfolio
```

Review the GitHub Actions result after each update. The source-preservation check compares the class project with the recorded file hashes; intentional changes to those files require reviewing and updating the manifest as well.
